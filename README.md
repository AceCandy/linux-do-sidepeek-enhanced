# Linux.do SidePeek Enhanced（二次开发版）

由 **AceCandy** 维护的独立二次开发版，基于 [BobDLA/linux-do-sidepeek](https://github.com/BobDLA/linux-do-sidepeek)。原始抽屉预览、回复、图片预览等能力来自上游及其贡献者；本仓库保留上游 Git 历史和致谢，不是上游官方发行版。

## 与原版相比，二开增加了什么？

以下比较以本仓库开始二开前的上游代码 [BobDLA/linux-do-sidepeek · `4bc7255`](https://github.com/BobDLA/linux-do-sidepeek/tree/4bc7255bc5c53194fb7962981badf9ef857313b1)（当时扩展版本为 **0.6.0**）为基准，对照本二开版 **0.8.0** 的累计变化，而非仅比较上一版本。上游后续可能继续更新，这不是对上游最新版本的实时比较。

| 功能 | 原版（上述基准） | 本二开版 |
| --- | --- | --- |
| 主题预取、缓存与阅读恢复 | 没有跨关闭、切换主题的内存缓存 | **新增**可见标题每秒最多 2 个预取请求，与已打开主题共用最多 100 个主题的内存缓存，10 分钟过期；重新打开恢复阅读位置，缓存超过 30 秒时后台刷新 |
| 回复框位置 | 固定布局，不支持拖动 | **新增**桌面端拖动回复框并记忆位置；窄屏（≤720px）保持固定布局 |
| 整页模式快捷回复 | iframe 模式隐藏抽屉自己的回复入口 | **新增**整页模式中的抽屉快捷回复入口；成功发送后刷新 iframe 并定位新回复。仍需站点登录及有效权限 |
| 表情反应 | 单一点赞/取消点赞 | **增强**为多表情选择和反应统计，使用站点反应接口；可用表情取决于站点配置与接口支持 |
| 查看某层的直接回复 | 显示回复数量 | **新增**点击回复数量查看直接回复列表，显示楼层、用户和内容摘要，并尝试补齐尚未加载的数据 |
| 沿回复关系跳转 | 没有被回复楼层入口及回复列表跳转 | **新增**被回复楼层入口、回复列表跳转；已加载楼层在抽屉内定位，未加载楼层在新标签打开 |
| 预览是否标记已读 | 预览按站点正常进帖方式发起计数/阅读请求，没有独立开关 | **新增**阅读状态开关；自动/智能模式按实际可见楼层上报阅读时间，预取不计已读；整页模式由原网页处理 |
| 原站正文与信任等级 | 无对应二开接入 | **新增**原站正文装饰、轮播和 Boost 组件接入，以及可悬停展开、可隐藏的 Connect 信任等级面板 |
| 长帖继续加载 | 已支持无限滚动，每批加载后重新渲染主题视图 | **优化**完整主题、默认顺序、全部作者且无目标楼层时只追加新楼层，保留现有内容与滚动位置；其他视图仍走完整渲染 |
| 操作与页面布局 | 已有上一帖、下一帖、选项、刷新、回复、新标签打开、关闭等文字按钮 | **优化**为紧凑图标、右下悬浮刷新/回顶/回复、顶栏左上缺口、可选宽屏列表靠左及居中设置弹窗；头像菜单帖子链接可直接预览 |
| 预览默认值 | 默认整页模式，可切换智能预览 | **调整**为“自动（推荐）”，优先请求主题数据，失败时回退整页；原版智能模式也已有整页回退，不能把回退能力算作新增 |
| 安装与设置保存 | 仓库提供浏览器扩展，以站点 localStorage 保存设置 | **新增**独立油猴发行版和 GreasyFork 安装入口；油猴版优先使用脚本管理器存储并兼容旧本地设置，扩展版继续使用 localStorage |

**原版已有、二开继续保留的功能**：抽屉预览、上一帖/下一帖、主题及指定楼层回复、快捷键发送、粘贴图片上传、无限滚动、全屏图片预览、收藏和复制帖子链接、只看楼主、最新回复视图、字号及抽屉宽度设置等。这些基础能力来自上游及其贡献者，不列为二开新增。

上表根据代码差异核实，不代表所有线上交互均已完成测试。自定义表情、实际回复/上传和 Firefox 完整交互仍需进一步回归；回复列表也不保证一次加载全部回复。[查看累计代码差异](https://github.com/AceCandy/linux-do-sidepeek-enhanced/compare/4bc7255bc5c53194fb7962981badf9ef857313b1...main)。

## 当前功能

- 智能预览优先复用原站正文组件与样式（不使用 iframe），支持原站轮播等正文装饰；正文组件不可用时回退现有智能渲染。接入依赖 Discourse 内部模块，网站升级可能触发回退。原站图片放大沿用站点交互。
- 楼层统计与操作合为一排，以 `|` 分隔，不再显示楼层阅读量。表情汇总可点击选择、切换或取消反应。
- 回复、刷新当前帖子和智能回顶入口悬浮于右下角，刷新在回顶左侧，顶部不再重复显示；Boost 使用紧凑尺寸。主题标签并入标题信息区。便捷阅读说明每次页面加载仅浮现一次，8 秒后消失，也可点 × 关闭，不占用正文空间。
- 支持原站 Boost 气泡及火箭输入入口，是否可用由原站权限决定；依赖原站组件，模块不可用时不显示 Boost。长代码在正文内横向滚动，不撑宽楼层。
- 可见主题标题异步预取：当前前台页面每秒最多启动 2 个请求，预取并发最多 2 个；整页模式及后台页面暂停。点击复用正在进行的请求或已缓存数据，预取不发送浏览跟踪与阅读上报。
- 当前主题缓存统一为最多 100 个主题，获取后 10 分钟过期，按最近使用淘汰；同一主题不同楼层共享正文、分别保留阅读位置。缓存仅存于当前页面内存，刷新清空。
- 智能/自动预览按实际可见楼层同步阅读进度：前台且有焦点时采样，约每 5 秒提交一次，切帖或关闭时提交剩余进度。可在“阅读状态”中关闭；最新回复或末楼上报可能推进整帖已读位置。
- 左侧信任等级面板：收起时仅显示“等级”，悬停后展示目标等级和指标；可在选项中隐藏并停止自动获取数据。鼠标悬停展开、移开收起；点击可固定展开，再次点击或 Esc 收起，触屏和键盘仍可操作。支持手动刷新和每五分钟刷新；收起或后台标签页暂停自动请求。首次使用请在 [Connect](https://connect.linux.do/) 完成登录或站点验证。
- 选项支持“宽屏帖子列表靠左”：默认关闭，开启后大于 1120px 的列表容器始终靠左；保留原站边栏的正常展开、收起与布局。不绑定抽屉开关、不改变抽屉模式，悬浮抽屉打开和关闭时列表位置与宽度不变。关闭靠左选项后恢复原站布局。设置弹窗居中限高，上下留白，内部滚动。
- 原站边栏按钮和 Logo 靠左；大于 720px 时抽屉左上留出缺口，原站语言、搜索、会话、头像等入口保留原 DOM，位于抽屉工具按钮左侧，收起后恢复右上角。头像菜单内通知、回复、点赞对应的帖子可直接进入预览并收起菜单；保留楼层路径，但不额外清除通知红点。
- 面板接入参考 [LDStatus v1.13](https://github.com/1e0n/LinuxDoStatus/blob/master/LDStatus.user.js) 的数据来源与页面结构，按扩展方式独立实现；没有加入原脚本的更新器、拖动、自选主题或旧版每日统计。扩展新增 Connect 访问权限，油猴版新增对应跨域授权。
- 状态面板只读取站点统计，不自行增加计数。浏览跟踪与 `/topics/timings` 阅读上报分别处理；最终已读状态及等级统计由站点决定，可能延迟。详见 [统计口径核对](doc/status-and-reading.md)。
- 拦截站内主内容区里的主题链接点击，改为右侧抽屉预览
- 优先通过 Discourse 的 topic JSON 接口渲染内容
- 自动/智能预览支持选择是否发起阅读跟踪请求；整页模式的阅读状态和计数由原网页处理
- 接口不可用时，自动回退为右侧 iframe 整页预览
- 支持在抽屉内直接回复主题或指定楼层，支持 Markdown，`Ctrl+Enter` / `Cmd+Enter` 快捷发送
- 主题级回复默认使用头部 `回复主题` 入口；右侧悬浮 `回复` 按钮可在设置里单独开启
- 回复框支持直接粘贴图片并自动上传，插入与站点原生回复一致的 `upload://` Markdown
- 支持无限滚动自动加载更多帖子；下滑接近底部会自动拉取后续回复，底部显示加载进度
- 支持抽屉内图片点击全屏放大预览；点击遮罩层、右上角关闭或按 `Esc` 可退出
- 带普通外链的图片仍按原链接打开；指向原图的图片链接会优先走抽屉内预览
- 支持右上角 `选项` 按钮弹出临时设置窗口
- 设置窗口支持切换：`预览模式`、`内容范围`、`正文字号`、`作者过滤`、`回复排序`、`悬浮回复入口`、`抽屉模式`、`抽屉宽度`
- 设置窗口支持 `关闭` 按钮、点击空白区域关闭、`Esc` 关闭
- 设置修改后会自动保存到本地，下次打开继续生效
- 支持拖动抽屉左边缘来自定义宽度（窄屏下可能不可用）
- 支持 `上一帖` / `下一帖` 快速浏览当前列表
- 支持 `Alt + ↑ / Alt + ↓` 快捷切换上一帖 / 下一帖
- 支持 `首帖 + 最新回复`：智能预览默认仍是正常顺序；切到这个模式后，首帖固定在顶部，长帖会优先显示最新一批回复
- 支持 `挤压模式` / `浮层模式` 两种抽屉模式；浮层模式下支持点击抽屉外区域关闭
- 支持在“首帖 + 最新回复”视图下手动刷新最新回复，刷新时尽量保留当前滚动位置
- 列表页“查看 x 个新的或更新的话题”提示条会固定在中间栏顶部区域，点击后更容易回顶刷新
- 抽屉内会为楼主回复显示 `Topic Owner` 标记，帮助快速识别楼主发言
- 每次页面加载后首次打开时会显示一次预览说明，提醒抽屉视图与原帖页可能略有差异
- 标签对象会自动提取可读名称，避免显示 `[object Object]`

## 使用方式

1. 打开任意带主题链接的页面，例如首页、`/latest`、搜索页或用户发帖流
2. 点击任意主题标题，右侧抽屉会展开
3. 如需调整预览行为，点击右上角 `选项`
4. 如需完整原帖页，点击右上角 `新标签打开`
5. 如需关闭抽屉，按 `Esc` 或点击右上角 `关闭`

## 浏览计数验证

1. 在列表里找一个相对小众、当前浏览数较稳定的帖子
2. 先记下它在列表中的 `浏览` 数字
3. 用左键点标题，测试右侧抽屉的智能预览或整页模式
4. 停留几秒后回到列表，刷新看看 `浏览` 是否增长
5. 为避免数字乱跳，测试时尽量选同时在线人数少、别人不太会点开的帖子


## 预览选项

- `预览模式`
  - `自动（推荐）`：默认使用主题数据预览，接口不可用时回退整页
  - `智能预览`：通过 JSON 接口只拉取帖子内容，渲染更快、界面更干净，支持抽屉内回复和无限滚动
  - `整页模式`：以 iframe 嵌入论坛原帖页。内容与原帖 100% 一致——包括投票、嵌入、动态组件等智能预览无法还原的元素；也作为智能预览接口不可用时的降级方案。注意：二开版在整页模式也提供抽屉快捷回复入口，发送成功后刷新 iframe 定位新回复；浏览计数由 iframe 内页面自行处理
- `内容范围`
  - `完整主题`
  - `仅首帖`
- `正文字号`
  - `13px` 到 `18px`
  - 仅智能预览可用；会同步调整正文和 `pre` / `code` 的字号
- `作者过滤`
  - `全部作者` / `只看楼主`
  - 只在智能预览里过滤显示，不影响原帖实际内容
- `回复排序`
  - `默认顺序`（智能预览默认）
  - `首帖 + 最新回复`（长帖下优先显示最新一批回复，不代表整帖一次性完整倒序）
- `悬浮回复入口`
  - `关闭` / `开启`
  - 关闭后只保留头部 `回复主题`，开启后额外显示右侧悬浮快捷入口
- `抽屉模式`
  - `挤压模式` / `浮层模式`
  - 浮层模式下点击抽屉外区域可直接关闭
- `抽屉宽度`
  - `窄` / `中` / `宽` / `自定义`
  - 也可以直接拖动抽屉左边缘调整，窄屏下可能不可用
- `恢复默认`
  - 一键恢复为默认设置

## 安装

### Chrome / Edge

1. 打开扩展管理页
2. 打开“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择下载 ZIP 解压后包含 `manifest.json` 的目录

### Firefox

1. 打开 `about:debugging#/runtime/this-firefox`
2. 点击“临时载入附加组件”
3. 选择当前目录里的 `manifest.json`
4. 或者选择 Release 附件里的 `*-firefox-unsigned.xpi` 做临时安装

注意：
- 上面的 Firefox 安装方式主要用于本地测试或临时加载
- 如果要给普通 Firefox 用户长期安装，仍需要经过 Mozilla 的签名分发流程

[Greasy Fork 脚本 595341](https://greasyfork.org/zh-CN/scripts/595341) 已启用自动源代码同步，来源是 GitHub 最新正式 Release 的油猴附件：

```text
https://github.com/AceCandy/linux-do-sidepeek-enhanced/releases/latest/download/linuxdo-sidepeek.user.js
```

- 发版前更新 `manifest.json` 版本号，运行 `node scripts/build-userscript.cjs` 并提交生成文件；Release 必须包含同名 `linuxdo-sidepeek.user.js` 附件。
- 发布新的正式 Release 并设为 Latest 后，Greasy Fork 定期拉取该附件，按脚本中的 `@version` 更新；不是即时推送，检查可能有延迟。
- 普通 `main` 提交、尚未生成正式 Release 的标签、草稿和预发布不会直接更新 Greasy Fork；只有最新正式 Release 的附件变化才成为同步源。
- 不需要保存 Greasy Fork 密码、登录 Cookie 或 Webhook 密钥，也没有额外的发布分支。
- 此配置同步脚本代码与版本，Greasy Fork 简介和更新日志仍单独维护。可在脚本“管理 → 源代码同步”中检查状态或手动触发同步。

## 适用页面

当前默认会在 `https://linux.do/*` 注入，并优先支持主内容区里的主题链接场景，例如：

- 首页、`latest`、`new`、`unread`、`top`、`hot`
- 分类页、标签页
- 搜索结果页
- 用户发帖流、收藏等带主题链接的列表页

头像菜单内通知、回复、点赞对应的本站帖子链接也可预览。为避免误拦截，帖子详情正文、编辑器及其他弹层菜单等区域里的主题链接默认不会接管；个人主页、全部通知等非帖子链接及 Ctrl/Command/中键、新标签操作仍保持原样。

## 代码结构

扩展仍可直接加载，无需构建。油猴发行版由同一份源码自动生成，不再手动复制维护：

```bash
node scripts/build-userscript.cjs
bash scripts/check.sh
```

公共逻辑修改 `src/content.js`、`src/content.css` 或 `src/native-renderer.js`；油猴元数据和存储适配修改 `userscript/template.js`。版本号来自 `manifest.json`，生成的 `.user.js` 继续入仓并用于发布。`node scripts/build-userscript.cjs --check` 只检查不写文件；CI 和发布检查会拦截未同步产物。

- `manifest.json`
- `src/content.js`
- `src/content.css`
- `src/background.js`
- `src/native-renderer.js`
- `userscript/template.js`
- `scripts/build-userscript.cjs`
- `CHANGELOG.md`
- `.github/workflows/release.yml`
- `AGENTS.md`

## 已知说明

- 抽屉预览是便捷阅读视图，不保证和原帖完整页面 100% 一致
- `首帖 + 最新回复` 更偏向最新回复流视图；长帖下默认不会把整帖所有回复一次性完整倒序
- 某些帖子里的外链资源、嵌入内容、动态组件，在抽屉里可能和原帖页表现不同
- 如果需要最完整的展示效果，请使用 `新标签打开`
